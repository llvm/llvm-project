  * [\[RFC\] Default Alignment Behavior for COMMON Block Members in Flang](https://discourse.llvm.org/t/default-alignment-behavior-for-common-block-members-in-flang/92753)
    * *Add command line options to Flang to allow users to select layout of `COMMON` block members. Discuss what Fortran’s default should be.*
    *  Flang does not have alignment behavior for `COMMON` block members, which is unlike any other Fortran compiler. Flang is partially padded, but not like GFortran’s padding. Other compilers use packed `COMMON` blocks.
    * RFC shows behavior of various compilers. Should Flang be changed to have the same default as one of these other compilers?
    * Daniel’s preference is to follow ifort/ifx, which is to pack `COMMON` block members
    * Themos: Checking that the RFC does not violate the requirements of the Fortran standard
    * Daniel: No violations as far as he is aware
  * [\[RFC\] Representing Fortran aliasing rules in LLVM IR: options and costs](https://discourse.llvm.org/t/rfc-representing-fortran-aliasing-rules-in-llvm-ir-options-and-costs/92828)
    * *Interactions between Fortran’s aliasing guarantees in LLVM’s TBAA metadata*
    * Related PR: [https\://github.com/llvm/llvm-project/pull/242549](https://github.com/llvm/llvm-project/pull/242549)

    * Separate issue found during investigation. PR opened for that.
