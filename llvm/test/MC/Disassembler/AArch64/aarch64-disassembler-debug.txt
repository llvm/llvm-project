# between encodings, so a name baked into the body would name the wrong one.
# CHECK: decodeInstruction: insn = 0x919998e5
# CHECK: OPC_Decode for opcode [[OPC:[0-9]+]]: insn using DecodeAddSubImmShift : FAIL
