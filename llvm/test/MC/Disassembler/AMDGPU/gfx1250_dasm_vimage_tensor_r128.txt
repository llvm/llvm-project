# RUN: llvm-mc -disassemble -triple=amdgpu12.50 -show-encoding %s | FileCheck --check-prefix=GFX1250 %s

# The gfx1250 tensor instructions have no R128 modifier: the assembler requires
# r128=0 (see llvm/test/MC/AMDGPU/gfx1250_asm_vimage_err.s), so every encoding
# the assembler can emit has the R128 bit clear. The disassembler, however,
# still decodes that bit into the $r128 operand, so an encoding with R128 = 1
# is printed with a trailing "r128" that the assembler rejects with
# "instruction must set modifier r128=0", i.e. the output does not reassemble.
#
# FIXME: An encoding with the R128 bit set is not a valid gfx1250 tensor
# instruction. It should be reported as an invalid instruction encoding instead
# of being disassembled into this non-reassemblable form. The checks below
# record the current behavior, not the desired one.
